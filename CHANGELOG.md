# Changelog

## 0.1.0

- 🧠 Capture Context from the cell toolbar or `Ctrl+Alt+C`, with six templates: Experiment, Decision, Assumption, Data Context, Result, General Note
- Template mode (editable cell) and guided mode (input box per field)
- Context ID, created/updated timestamps, notebook path, cell id/index and content hash in every context cell
- Code snapshot per capture; per-cell status bar flags "code changed since capture"
- Timeline view grouped by time, type or cell; diff since capture; mark linked code as current
- Export context log to Markdown or JSON
